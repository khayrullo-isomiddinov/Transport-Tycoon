MINI TRANSPORT TYCOON
=====================

An isometric transport-management game. Build roads, connect towns, run buses
and trucks, and keep your company out of bankruptcy.

Made by Team 404 (Software Technology course, ELTE) with Java 17 and LibGDX.
Source code: https://github.com/khayrullo-isomiddinov/Transport-Tycoon


RUNNING THE GAME (Windows 10/11, 64-bit)
----------------------------------------
1. Extract the whole zip to a folder (don't run it from inside the zip).
2. Open the MiniTransportTycoon folder and double-click MiniTransportTycoon.exe.

No Java installation is needed; a Java runtime is bundled in the "runtime" folder.

If Windows SmartScreen says "Windows protected your PC", click "More info" and
then "Run anyway". The game is not code-signed because it is a free student project.

Requires a GPU with OpenGL 2.0 or newer (any machine from the last decade).


CONTROLS
--------
Left click           Place the selected item / use the selected tool
Left click + drag    Place along several tiles
Right click          Remove an item / sell a vehicle at a garage
WASD / arrow keys    Pan the map (mouse wheel also pans)
Ctrl + mouse wheel   Zoom
Click the minimap    Jump to that area
1 / 2                Choose bus / truck, then click a connected garage to buy
L                    Details for the hovered object
Z / X                Shorter / longer horizontal green light
C / V                Shorter / longer vertical green light
R                    Reset traffic-light timing
Esc                  Pause menu


QUICK START
-----------
1. Enter a company name, pick a difficulty and map size, press PLAY.
2. Connect towns with roads (roads auto-connect into corners and junctions).
3. Make sure a garage touches your road network.
4. Press 1 (bus) or 2 (truck) and click the garage to buy a vehicle.
5. Vehicles carry passengers and goods between towns and earn money per delivery.
6. Watch maintenance costs: older vehicles cost more to run.
