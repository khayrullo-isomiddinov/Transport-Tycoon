# Mini Transport Tycoon v0.1.0

First public build. A free, self-contained Windows download: no Java installation needed.

## What's in this release

- Randomly generated isometric maps (64×64 up to 1024×1024) with terrain heights, water,
  forests, towns and industry
- Road building with automatic corners, T-junctions and intersections, plus slope limits
- Terraforming (raise/lower tiles), and placing water and forest
- Passenger buses and goods trucks, bought and sold through garages connected to roads
- Transport demand between towns; delivery income for passengers and goods
- Economy: construction, vehicle and terraforming costs, vehicle maintenance that rises
  with age, bankruptcy and a game-over screen
- Traffic lights that vehicles obey, with adjustable timing while playing
- Three difficulty levels (starting capital $150k / $100k / $50k)
- Four simulation speeds (paused, 1×, 2×, 4×)
- Clickable minimap, hover tile info and an object inspector
- Main menu, in-game how-to-play screen and pause menu

## Known limitations

- No save/load yet: each session starts a new map
- No sound or music
- Windows x64 only for this release (the game runs on macOS/Linux from source; see the README)
- The executable is not code-signed, so Windows SmartScreen shows a warning on first launch
- Balance is still being tuned

## Download contents

`MiniTransportTycoon-0.1.0-windows-x64.zip`: extract it and run
`MiniTransportTycoon/MiniTransportTycoon.exe`.
